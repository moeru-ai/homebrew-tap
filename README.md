# Moeru AI Homebrew Tap

This tap distributes the AUV command-line interface for Apple Silicon and
Intel Macs.

## Install

```sh
brew install moeru-ai/tap/auv
```

## Upgrade

```sh
brew upgrade moeru-ai/tap/auv
```

## Uninstall

```sh
brew uninstall auv
```

AUV source code and releases are available at
<https://github.com/moeru-ai/auv>.
